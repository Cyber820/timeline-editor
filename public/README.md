
# public：电子游戏史时间轴与二维矩阵前端

**文件路径：`public/README.md`**  
**文档更新：2026-11-25**

## 1. 目录定位

`public/` 是 Railway 网站的静态资源目录，包含原有电子游戏史横向时间轴、事件编辑和辅助页面，以及新增的二维矩阵页面。

项目遵循两条原则：

1. **保留原有时间轴功能。** 二维矩阵是独立页面，原则上只新增或修改 `public/src/matrix/` 中的模块，复用已存在的数据读取、过滤、样式引擎；不为了二维矩阵修改原时间轴的绘制流程。
2. **分级维护文档。** 本 README 说明 `public/` 的页面和下级目录；`public/src/README.md` 说明模块目录；`public/src/matrix/README.md` 详细说明二维矩阵中的文件、函数、参数、返回值和依赖。项目根目录 `README.md` 负责更高一层的结构与部署说明。

## 4. 二维矩阵的数据与坐标约定

- 数据来源：原有世界中文版 Events 数据源。
- 原时间轴接口：`/exec`，**保持原行为**。
- 二维矩阵接口：`/exec?action=matrix`。
- 矩阵横轴共有 **378列**：366个完整月日坐标，以及每月前置的1个“日期未知”坐标。
- 日期精确到日：`YYYY-MM-DD`；只确定年月：`YYYY-MM-00`。例如 `1984-06-00` 位于6月“00日”列。
- 横轴以2000年作为闰年参考，因此包含2月29日；历史事件的实际日期仍须通过其所属年份的日期校验。
- 纵轴为**从新到旧的连续年份**，保留无事件的空白年份；过滤不会删除原纵轴年份范围。
- 若跳转到目前年份范围之外的有效年份（1—9999），矩阵会扩展年份范围，并添加缺失年份的空白行。
- 同一年、同一月日的多条事件在同一日期单元格内纵向排列。
- Apps Script 已经排除的记录不会被计入前端 `skipped`；因此其数字不能等同于源表非法日期总数。

## 5. 二维矩阵已实现的功能

### 5.1 浏览与可视化

- 378列固定日期坐标、连续年份纵轴。
- 横向与纵向原生滚动。
- 固定日期表头、固定年份标签。
- 无矩阵网格线，事件卡片保留边框。
- 相同坐标的多事件堆叠显示。

### 5.2 过滤与样式

- 复用原时间轴的过滤界面与 AND／OR 规则引擎；支持规则新增、删除和重置。
- 五个样式窗口：事件、平台、主机、公司、地区。
- 支持字体颜色、背景颜色、边框颜色、字体和光晕颜色的规则绑定与应用。
- 样式仅存放在当前页面内存中，刷新后恢复默认；不写入原时间轴的样式状态。
- 过滤重绘后，自定义样式仍可匹配新创建的事件卡片。

### 5.3 日期跳转（横轴）

- “日期跳转”面板提供月份和日期选择。
- 日期允许 `00`（每月日期未知）；2月29日也作为固定横轴坐标存在。
- **不依赖对应日期是否存在事件。**
- 只改变横向滚动位置，尽可能将目标日期放在可视区域中央。
- 高亮目标日期表头；不修改过滤条件、年份位置和事件卡片样式。

### 5.4 年份跳转（纵轴）

- “年份跳转”面板接受1至9999的整数年份。
- **不依赖对应年份是否存在事件。**
- 已有年份可直接跳转；范围外年份会先补足连续空白年份行。
- 只改变纵向滚动位置，尽可能将目标年份放在可视区域中央。
- 高亮目标年份标签；不修改当前日期、过滤条件及事件样式。

## 6. 尚未实现：截图取景与缩放

下一阶段先明确截图／截取模式的实际效果，再编写代码。当前**尚未实现**以下功能：

- 横轴、纵轴独立缩放和显示密度调整。
- 选定日期／年份坐标范围并导出图片。
- 输出包含日期表头、年份标签和完整事件卡片的PNG。
- 独立于浏览器窗口大小的高分辨率图片导出。
- 为超大范围截图或极端年份跨度进行专门的性能优化。

设计方向：以矩阵坐标作为截取范围的依据，保留当前过滤结果与自定义样式；既支持单日纵向历史事件截取，也支持某一年或连续数年的横向事件展示。此处仅记录**待讨论目标**，不视为已完成的技术方案。
